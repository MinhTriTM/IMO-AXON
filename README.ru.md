## 🌟 Обзор проекта
**MIMO-AXON** — это мультиагентная ИИ-экосистема, предназначенная для автоматизации перевода, создания субтитров и дубляжа видео/аудио в промышленных масштабах. Проект использует логику Chain-of-Thought (CoT) для обеспечения абсолютной точности в культурном контексте.

Основная цель: Оптимизация потребления **1,5 триллиона токенов** в рамках программы Xiaomi MIMO 100T.

## 🏗 Архитектура системы
Система координирует работу 4 специализированных агентов:
*   **Visual Scout (Агент A):** OCR жестких субтитров с использованием **Gemini 2.5 Flash Lite**.
*   **Acoustic Analyst (Агент B):** Извлечение аудио и преобразование речи в текст (STT) с помощью **OpenAI Whisper**.
*   **Contextual Translator (Агент C):** Контекстно-зависимый перевод с использованием **Gemini 1.5 Pro**.
*   **Neural Dubber (Агент D):** Синтез речи и синхронизация времени с помощью **Edge-TTS**.

## 📁 Модульная структура
- **`src/core/`**: ИИ-движки (OCR, Vision).
- **`src/modules/`**: Логика TTS, STT, Дубляжа.
- **`docs/`**: Предложения, планирование и журналы исследований.
- **`data/`**: Управление вводом/выводом медиафайлов.
- **`web/`**: Панель мониторинга в реальном времени.

## 🛠 Инструкции
- Запустите `setup_project.bat` для организации рабочего пространства.
- Откройте `web/index.html` для мониторинга прогресса и использования токенов.
