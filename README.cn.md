## 🌟 项目概述
**MIMO-AXON** 是一个多智能体人工智能生态系统，旨在工业化规模上自动执行视频/音频的翻译、字幕制作和配音。该项目利用思维链 (Chain-of-Thought, CoT) 推理来确保文化语境的绝对准确性。

核心目标：优化 **1.5 万亿 Token** 在小米 MIMO 100T 计划中的使用效率。

## 🏗 系统架构
系统协调 4 个专业智能体：
*   **Visual Scout (智能体 A):** 使用 **Gemini 2.5 Flash Lite** 进行硬字幕 OCR。
*   **Acoustic Analyst (智能体 B):** 使用 **OpenAI Whisper** 进行音频提取和语音转文本 (STT)。
*   **Contextual Translator (智能体 C):** 使用 **Gemini 1.5 Pro** 进行语境感知的翻译。
*   **Neural Dubber (智能体 D):** 使用 **Edge-TTS** 进行语音合成和时间同步。

## 📁 模块化结构
- **`src/core/`**: AI 引擎 (OCR, 视觉)。
- **`src/modules/`**: TTS, STT, 配音逻辑。
- **`docs/`**: 提案、规划和研究日志。
- **`data/`**: 媒体输入/输出管理。
- **`web/`**: 实时监控控制面板。

## 🛠 操作指南
- 运行 `setup_project.bat` 以整理工作空间。
- 打开 `web/index.html` 以监控进度和 Token 使用情况。
