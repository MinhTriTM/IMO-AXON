# Module: Dubbing & Audio Processing

Thư mục này quản lý toàn bộ quy trình lồng tiếng và thuyết minh phim.

## 🛠 Thành phần:
- `TMF.py`: Script chính điều khiển quy trình lồng tiếng.
- `TMF_GoogleTTS.py`: Tích hợp Google Cloud TTS chất lượng cao.
- `VLC_AI_Dubber/`: Tích hợp trình phát media.
- `TMF_Local_Engine/`: Các mô hình TTS chạy local (Melo, Sherpa).

## 🚀 Hướng dẫn:
Đặt file video và sub vào `data/input/`, sau đó cấu hình đường dẫn trong các file script tương ứng.
