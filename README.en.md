## 🌟 Project Overview
**MIMO-AXON** is a multi-agent AI ecosystem designed to automate translation, subtitling, and dubbing for video/audio at an industrial scale. The project leverages Chain-of-Thought (CoT) reasoning to ensure absolute accuracy in cultural context.

Core Goal: Optimize the consumption of **1.5 Trillion tokens** within the Xiaomi MIMO 100T program.

## 🏗 System Architecture
The system orchestrates 4 specialized Agents:
*   **Visual Scout (Agent A):** Hard-sub OCR using **Gemini 2.5 Flash Lite**.
*   **Acoustic Analyst (Agent B):** Audio extraction and Speech-to-Text using **OpenAI Whisper**.
*   **Contextual Translator (Agent C):** Context-aware translation using **Gemini 1.5 Pro**.
*   **Neural Dubber (Agent D):** Voice synthesis and time-syncing using **Edge-TTS**.

## 📁 Modular Structure
- **`src/core/`**: AI Engines (OCR, Vision).
- **`src/modules/`**: TTS, STT, Dubbing logic.
- **`docs/`**: Proposals, Planning, and Research logs.
- **`data/`**: Media Input/Output management.
- **`web/`**: Real-time Monitoring Dashboard.
