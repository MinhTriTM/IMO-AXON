# 🤝 Hướng dẫn Đóng góp vào MIMO-AXON (Contributing Guide)

Chào mừng bạn đến với cộng đồng phát triển **MIMO-AXON**! Chúng tôi luôn hoan nghênh sự đóng góp từ các nhà phát triển AI trên toàn thế giới để cùng nhau xây dựng một hệ sinh thái xử lý đa phương tiện mạnh mẽ hơn.

## 🚀 Các cách bạn có thể đóng góp

1.  **Phát triển Module mới:** Xây dựng thêm các module hỗ trợ ngôn ngữ mới hoặc engine TTS/STT khác.
2.  **Tối ưu hóa Performance:** Cải thiện tốc độ xử lý frame (FFmpeg) hoặc giảm tiêu thụ token.
3.  **Báo lỗi (Bugs):** Gửi các báo cáo lỗi thông qua GitHub Issues.
4.  **Tài liệu (Docs):** Cải thiện các bản dịch hoặc viết thêm hướng dẫn kỹ thuật.

## 🛠 Quy trình Pull Request (PR)

1.  **Fork** repository này.
2.  Tạo nhánh (branch) mới: `git checkout -b feature/AmazingFeature`.
3.  Thực hiện thay đổi và **Commit**: `git commit -m 'Add some AmazingFeature'`.
4.  **Push** lên nhánh của bạn: `git push origin feature/AmazingFeature`.
5.  Mở một **Pull Request** để hội đồng thẩm định xem xét.

## ⚖️ Tiêu chuẩn Code
-   Mọi mã nguồn mới phải tuân thủ kiến trúc **Modular** đã thiết kế.
-   Sử dụng **Relative Paths** cho mọi thao tác file.
-   Phải kèm theo file log tương tác (Lich_Su_Truy_Van) nếu code có sự can thiệp của AI Agent.
