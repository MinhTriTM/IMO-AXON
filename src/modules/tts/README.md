# Module: TTS & Text Processing

Thư mục này quản lý việc xử lý văn bản và chuyển đổi giọng nói cơ bản.

## 🛠 Thành phần:
- `fix_markdown.py`: Chuẩn hóa định dạng tài liệu nghiên cứu.
- `TTS_API_Google.py`: Script test API Google TTS.

## 🚀 Hướng dẫn:
Sử dụng các script này để tiền xử lý văn bản trước khi đưa vào module lồng tiếng.
